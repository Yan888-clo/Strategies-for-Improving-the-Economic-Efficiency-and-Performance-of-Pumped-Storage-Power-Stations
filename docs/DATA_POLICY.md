# 数据、来源与使用边界

本仓库以辽宁清原一期6×300 MW为案例。研究资料整理日为2026-11-16；每次更新分别记录检索时间和政策生效时间。

## 数据源与生成物

- `research/data/qingyuan_public_parameters.json`：48项公开参数与工程信息、11项推导量、19项来源、16项缺口及计算说明。
- `research/data/qingyuan_public_parameters.csv`：供下载的参数表；应与JSON保持同一版本。
- `research/data/economics_spot_20261115_96points.csv`：辽宁统一结算点2026-11-15的96点价格，非清原节点结算单。
- `research/data/stations_2023.json`：2023年历史容量电价样本；分类与价格均不是当前状态或当前报价。
- `research/sources/index.json`、`research/evidence/`：来源目录、核查说明及已取得的公开接口响应。
- 网页表格、脚本数据和下载包从上述资料构建；`dist/`不作为独立研究数据源。

## 证据分类

| 类别 | 可以支持什么 | 不应声称什么 |
| --- | --- | --- |
| 公开设计参数 | 工程边界、设计能量规模 | 实际商运记录或实际效率提升 |
| 设计物理模型试验 | 指定几何、比尺和测量界面的水力特征 | 全输水系统现场运行实测 |
| 商运累计报道 | 报道区间和口径内的累计值 | 闭合循环效率、全年财报或逐时记录 |
| 代理数据 | 明示位置与日期的算例 | 清原节点实际结算或全年行情 |
| 假设或替代曲线 | 方法验证与敏感性分析 | 清原实站最优策略或已实现收益 |
| 推导值 | 指明输入、公式、单位与边界的计算 | 独立实测数据 |

保留原始来源编号与原文定位。新资料须记录标题、机构、URL、发布/适用日期、取得日期、页码或章节、许可或权利提示及限制。参数冲突保留两个版本并说明采用理由，不能悄悄以新值覆盖旧来源。

## 计算边界

1. 效率比较统一计量点、统计期、发电任务和上下库初末状态；厂用电、天然来水、外部补水及储能变化按口径处理。
2. 300 MW是单机发电容量，不直接作为抽水最大入力；714 m是球阀设计水头，不代入运行水头；406 m正常水位差不等于390 m额定水头。
3. 下库局部损失系数0.141/0.347来自1:60设计模型试验，作用范围不是全站输水系统；图示米值为工程原型尺度。
4. 站外物理线损、输电容量、结算线损率和输配费用分开。2026-08起辽宁抽发电价按节点实时现货价格，费用及退减按适用规则处理。
5. 96点时间以北京时间、15分钟区间末端记录；保留负价，元/MWh除以1000转为元/kWh，算术均价不称电量加权均价。
6. 容量费不是利润；调峰、新能源消纳等系统价值不自动等于电站可留存现金收入。无完整财务资料不输出实际IRR、回收期或亏损排名。

## 尚缺资料

M01—M16完整保留在原参数JSON与`research/progress.json`中。没有完整库容曲线、机组效率曲面、稳定允许区及配套运行记录，`real_plant_efficiency_optimization_ready`应保持`false`。输电约束研究还需取得实际通道限额及适用时段，不能仅由500 kV接入电压推断输电能力。
